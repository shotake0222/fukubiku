# あてんど 受け皿サイト テンプレート

スタンプラリー／WebARへの**入口**になる1枚もののサイトです。
受注時にこのフォルダのファイルをコピーして、案件に合わせて差し替えて納品します。

会員登録やログインの仕組みは持ちません。参加者はこのページから
スタンプラリーのURLへ進み、そこで匿名の参加者IDが発行されます。
**個人情報を一切預からない**ので、クライアント側で名簿の管理義務が発生しません。

## 5種の使い分け

| ファイル | 用途 | 向いている相手 | 構成の特徴 |
|---|---|---|---|
| `01_kanko.html` | 観光周遊 | 観光協会・DMO・広域自治体 | 大きなヒーロー、見どころ、スポット一覧、モデルコース |
| `02_shotengai.html` | 商店街・食べ歩き | 商店街振興組合・まちづくり会社 | 店舗カードが主役。営業中バッジとクーポン帯 |
| `03_shisetsu.html` | 施設・館内 | 博物館・水族館・商業施設・展示会 | 開館状況を最上部に。フロア別スポット、遊び方3ステップ |
| `04_seichi.html` | IPコラボ・聖地巡礼 | 作品コラボ・ロケ地誘客 | 暗色でキービジュアル主役。キャラ紹介、マナー喚起、権利表記枠 |
| `05_jousetsu.html` | 常設・通年 | 公園・テーマパーク・沿線企画 | 「いま開催中の章」と季節ごとの入れ替え、リピーター導線 |

迷ったら、**開催期間で選ぶ**のがいちばん外しません。
単発なら 01/02/04、館内で完結するなら 03、通年なら 05 です。

## 受注時の差し替え手順

### ステップ1：必須（これをやらないと成立しません）

1. **スタンプラリーURL**
   全ファイルで `https://app.attend-ar.com/r/XXXXXXXXXX` を、
   管理画面で発行した配布用URLに置換します。
   **1ファイルにつき2〜4ヶ所**（ヘッダー・本文・スマホ固定バー）にあるので、
   エディタの一括置換で `XXXXXXXXXX` を検索してください。取りこぼすと、
   スマホのボタンだけ死んでいる状態になります。

2. **`○○` の置換**
   施設名・地名・店名がすべて `○○` になっています。一括置換ではなく、
   1ヶ所ずつ確認してください（文脈で入る語が違います）。

3. **フッターのリンク先**
   プライバシーポリシー・利用規約・お問い合わせが `href="#"` のままです。
   クライアントの既存ページへ向けるか、ページを用意します。

### ステップ2：見た目を合わせる

4. **色**
   各ファイル冒頭の `:root { --brand: ...; }` を、クライアントのコーポレートカラーに
   変更します。**ここだけ変えれば全体が揃う**ように組んであります。

5. **ロゴ**
   ヘッダーの `<span class="mark">○</span>` を
   `<img src="logo.png" alt="○○" style="height:32px">` に置き換えます。

6. **画像**
   `<div class="ph">画像 800×450</div>` が写真の入る場所です。
   `<img src="photo.jpg" alt="○○神社">` に置き換えてください。
   `.ph` のままでも表示は崩れないので、写真が間に合わない場合はそのまま納品して、
   後から差し替えることもできます。

### ステップ3：中身を合わせる

7. **スポット一覧**
   ラリーの並び順と番号を合わせます。管理画面のスポット順と揃えておくと、
   参加者が迷いません。

8. **バナー枠**
   `<a class="banner">` が自由枠です。数は増やしても減らしても構いません。
   クーポン・SNS・関連ページなど、クライアントが出したいものを入れます。

9. **不要なセクションの削除**
   `<section class="sec">...</section>` の単位で丸ごと消せます。
   お知らせ・モデルコース・FAQ など、埋まらないものは消したほうが仕上がります。

## 公開のしかた

1ファイルで完結しています。外部のCSSやJavaScriptを一切読み込まないので、
**HTMLを1つサーバーに置くだけ**で動きます。

- クライアントの既存サーバー／CMSに設置
- 静的ホスティング（Netlify、Vercel、S3 など）に置く
- WordPressの固定ページに貼る場合は、`<style>` ごと「カスタムHTML」ブロックに入れる

画像を使う場合は、HTMLと同じ階層に置いて `src="photo.jpg"` と相対パスで指定するのが
いちばん事故が少ないです。

## 補足

- **スマホ下部の固定ボタンは消さないでください。** 参加者の大半はスマホで、
  ページを下まで読まずに離脱します。常に見えている参加導線が、
  このサイトの成果をいちばん左右します。
- **AR導線のセクションには `▼▼▼ ここは必ず残してください ▼▼▼` とコメントを入れてあります。**
  クライアント側でページを編集する場合の目印になります。
- 埋め込み用URLを発行してある案件では、これらのテンプレートの代わりに
  クライアントの既存サイトへ直接iframeを貼る選択肢もあります。
  **すでに人が来ているページに置けるぶん、新規流入はそちらのほうが強い**ので、
  クライアントが集客力のあるサイトを持っている場合は埋め込みを提案してください。
